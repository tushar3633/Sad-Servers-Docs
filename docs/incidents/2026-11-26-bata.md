# "Bata": Find in /proc — Easy/Do

**Date:** 2026-11-19
**Status:** Resolved

## Symptom
Need to find a file in `/proc/sys` containing the string `secret:`, extract the text after the colon, and save it to `/home/admin/secret.txt` with a newline. No root access available.

## Investigation Log
*   **Hypothesis 1:** Use `grep -r` to recursively search the `/proc/sys` directory for the string.
    *   **Test:** `grep -rh "^secret:" /proc/sys 2>/dev/null`
    *   **Result:** Successfully found the matching line, but needed to extract just the password.
*   **Hypothesis 2 (Following the SadServers clue):** Use `find` to locate the file first, then extract the secret.
    *   **Test:** `find /proc/sys -type f -exec grep -El '^secret:' {} + 2>/dev/null`
    *   **Result:** Successfully output the exact path of the file containing the secret.
*   **Failed Attempts:** None. Noted that `/proc` is a virtual filesystem, so standard commands can sometimes hang if trying to read dangerous files like `sysrq-trigger`. Redirecting errors with `2>/dev/null` is essential.

## Solution
There are two valid ways to solve this. Both produce the exact same output and MD5 hash.

**Method 1: Using `grep -r` (Faster)**
```bash
grep -rh "^secret:" /proc/sys 2>/dev/null | cut -d':' -f2 > /home/admin/secret.txt
